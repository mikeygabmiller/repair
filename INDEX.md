## Every file, one line each

**Rules and tools**
- `CLAUDE.md`: how Claude answers; the owner's standing rules.
- `tools/unmerged.py`: start of chat, lists notes that never reached main.
- `tools/check.py`: drift checker (broken links, torque values not in specs.md, unlabeled
  numbers, unknown part numbers, bad complaint numbers). Run before merging.
- `tools/lookup.py`: refreshes recalls, complaints, EPA, VIN decode (`refresh`), and the
  bulletin list (`tsbs`).
- `tools/folded-branches.txt`: branches folded in by hand.

**Vehicle folder (`V/`)**
- `profile.md`: the car, recalls that apply, trim evidence.
- `open-issues.md`: what's broken now. `issues-history.md`: back story.
- `diagnostics.md`: decision tree for each open issue.
- `symptom-index.md`: new symptom → cheap-first path.
- `maintenance.md`: every schedule item, last done, next due, procedure link.
- `next-steps.md`: prioritized plan with cost and time.
- `specs.md`: every verified number with its source.
- `quick-reference.md`: fluids, tires, both fuse charts, bulbs, roadside (owner's manual).
- `parts.md`: part numbers, confirmed and not, plus the catalog by system.
- `log.md`: every job with date and mileage.
- `tsb-guide.md` / `tsbs.md`: bulletins by symptom / full list.
- `recalls.md`, `complaints.md`, `complaints-all.md`, `epa.md`, `vehicle.json`: official
  data (generated by `tools/lookup.py`).
- `owner-checklist.md`: what to photograph, call about, or look up at the library.
- `chilton-checklist.md`: Chilton items found / still missing.
- `plan-right-front-2026-10.md`, `plans/2026-11-catch-up-maintenance.md`,
  `plans/long-term-ownership.md`: plans.

**Procedures (`procedures/`)**: see `procedures/README.md`.

**Mods (`mods/`)**: `README.md` (ideas and rules), `tools-plan.md`,
`lighting-upgrades.md`, `plan-head-unit-2026-10.md`, `plan-hitch-storage-2026-10.md`,
`switch-slot-ideas/`.

**Sources (`sources/`)**: owner's manual PDF, Chilton pulls, project history (trust it for
what was done, never for specs). **Prompts (`prompts/`)**: Muse Chilton pulls (Part 1, 2, 3),
NotebookLM. **Receipts (`receipts/`)**: invoices (private).
